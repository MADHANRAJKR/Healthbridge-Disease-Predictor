## 🎯 Project Overview

An AI-powered disease prediction and symptom checker prototype built for HealthBridge Hospitals. The system accepts 15 structured patient features (demographics, vitals, binary symptoms), runs them through an optimised ML pipeline, and returns:

- 🩺 **Top-3 probable diagnoses** with confidence scores
- 🔍 **SHAP explanations** — which symptoms drove the prediction
- 📊 **Interactive Streamlit UI** with real-time charts
- 🚀 **FastAPI REST backend** with Swagger documentation

> ⚠️ **Disclaimer:** This is an educational prototype. It is NOT intended for clinical diagnosis or to replace qualified healthcare professionals.

## ⚡ Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the data pipeline
```bash
python src/data_pipeline.py
```
Generates `data/processed/features.csv` (30 diseases, ~3 000 rows).

### 3. Train models
```bash
python src/train.py
```
Trains Logistic Regression, Random Forest, and XGBoost. Picks best by macro-F1.
Saves `models/best_model.joblib`. Logs everything to MLflow.

### 4. Generate SHAP explanations
```bash
python src/explain.py
```
Saves plots to `reports/shap/`.

### 5. Start the API
```bash
uvicorn api.main:app --reload --port 8000
```
Visit `http://localhost:8000/docs` for the Swagger UI.

### 6. Launch the UI
```bash
streamlit run App/streamlit_app.py
```
Visit `http://localhost:8501`.

### 7. Run tests
```bash
pytest Tests/ -v
```
